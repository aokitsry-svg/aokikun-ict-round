# あおき君

**院内感染ラウンドを、もっとやさしく、たのしく。**

あおき君は、公開OSSの感染対策ラウンドアプリを Apache License 2.0 に基づいて改変した個人制作の Phase 1 試作Webアプリです。正式な医療情報システムではなく、元サービスとの公式な関係を示すものではありません。

## 主な機能

- 担当者名と病棟名・部署名を入力してラウンド開始
- 標準チェックリストでの A / B / C 評価
- CSV / Excel (`.csv` / `.xls` / `.xlsx`) チェックリスト取り込み
- 項目紐付き写真、一般写真、写真コメントの追加・削除
- 総評入力と箇条書き補助
- レポートプレビュー
- Word (`.docx`) 生成と、対応端末での共有
- 保存済みラウンドの端末内保存、再開、削除
- テーマ選択
- Service Worker による PWA 対応
- ブラウザ印刷による「印刷・PDF保存」

## データ保存と注意

- 保存方式は既存実装と同様に `localStorage` を使います。
- クラウド同期、API、認証、データベースはありません。
- 未保存の入力内容は、ページ再読み込みやタブ終了で失われる場合があります。
- ブラウザデータを消去すると、保存済みラウンドや取り込み済みチェックリストも失われる場合があります。
- 写真はブラウザ内で圧縮して保存しますが、容量上限に達した場合は不要な保存済みデータや写真を削除してください。

## Word出力

レポートプレビューから Word (`.docx`) を出力できます。Web Share API 対応端末では共有導線、非対応環境ではファイル保存導線を使います。

## PDF対応

新しいPDFライブラリは追加していません。レポートプレビューの `印刷・PDF保存` ボタンからブラウザの印刷機能を開き、環境側のPDF保存を利用します。

## PWA

本番ビルドでは `index.html` から Service Worker を登録し、アプリシェルとブランドアセットをキャッシュします。開発時のlocalhostでは古いService Workerとの混線防止のため登録解除します。
